\begin{abstract}
Exemplar-free analytic continual learners replace historical samples with
sufficient statistics, but high-dimensional analytic state can still dominate
memory. FLY-CL maps frozen ViT features to 10,000-dimensional sparse
winner-take-all codes and retains a dense FP32 Ridge Gram matrix. We propose
Square-Root Quantized Ridge (SRQ), instantiated as SRQ-FLY: a reusable backend
that stores the regularized system as an upper-triangular factor, keeps its
diagonal in FP32, quantizes its strict upper triangle groupwise to INT8,
updates it by blocked QR, and recovers classifier weights by triangular
solves. Across six paired replicates on CIFAR-100, CUB-200-2011, and a
disclosed legacy ImageNet-R split, SRQ-FLY reduces persistent learner state by
76.7--78.1\% while changing AIA by $-0.018$, $-0.083$, and $-0.062$
percentage points relative to same-width Exact FLY. At nearly equal state, it
exceeds lower-width Exact FLY by 0.132--0.856 AIA points. Direct-quantization
controls support factor-space compression over INT8 Gram quantization with
SPD repair. A train-only transfer to RanPAC's random-ReLU head reduces state
by 79.1\%; at equal state it outperforms reduced-width Exact and CountSketch
by 0.484 and 0.572 AIA points. On a controlled GACL-style generalized stream,
P2B reduces state by 72.6\% with a 0.139-point AIA loss. At width 20,000,
fixed INT8 narrowly fails a predeclared 0.25-point retention gate.
Across four paired runs on one Tesla T4, whole-process peak memory falls
13.9\%, but updates remain slower. SRQ is therefore an accuracy--memory trade-off for additive-Ridge
heads, not a universal plug-in or an accuracy-improving replacement for Exact
learning.

\section{Introduction}

Class-incremental learning requires one predictor over all classes observed so
far without task identity at inference. Replay can preserve historical
knowledge, but retaining images, embeddings, or codes causes memory to grow
with the stream. Analytic continual learners instead update a global
classifier from sufficient statistics and can avoid storing past samples under
fixed-feature assumptions~\cite{zhuang2022acil,zhuang2024foal}.

Eliminating replay does not eliminate state memory. FLY-CL~\cite{zou2026flycl}
uses a frozen backbone, sparse random projection, and sample-dependent
winner-take-all (WTA) coding. For a code width of $m=10{,}000$, its dense FP32
Gram matrix alone contains 100 million entries, or 400 MB. Reducing $m$ saves
memory but weakens the expanded representation, whereas directly quantizing
the Gram matrix can destroy positive definiteness and make the Ridge solve
fail.

SRQ-FLY addresses the state representation rather than the upstream feature
map. It stores a mixed-precision square root of the regularized Ridge system,
updates it with blocked QR, and obtains the classifier using triangular solves.
The design is inspired by factor-space quantization for Shampoo
preconditioners~\cite{li2025fourbit}, but SRQ-FLY uses INT8 rather than 4-bit
storage, has no optimizer momentum or inverse fourth root, and does not inherit
the optimizer convergence theorem.

This paper makes three contributions. First, it introduces a compressed
additive-Ridge backend whose primary instantiation retains FLY's width and
prediction semantics. Second, it provides explicit state accounting and a
structural positive-definiteness argument together with cumulative system,
solution, logit, and margin perturbation bounds. Third, it evaluates the
accuracy--memory trade-off against same-width Exact FLY, state-matched
lower-width FLY, raw-feature Ridge, and direct-quantization controls, then
tests backend transfer on a distinct RanPAC random-ReLU frontend and on a
controlled GACL-style generalized stream with class reappearance.

\section{Related Work}

\subsection{Analytic Continual Learning}

ACIL derives recursive analytic class-incremental learning without storing
historical samples~\cite{zhuang2022acil}. F-OAL develops forward-only online
analytic learning~\cite{zhuang2024foal}, while GACL studies generalized
analytic continual learning~\cite{zhuang2024gacl}. REAL, MoAL, and AnaCP focus
on improving the representation used by analytic classifiers
~\cite{he2024real,gao2025moal,momeni2025anacp}. SRQ-FLY instead targets the
persistent quadratic state produced by a fixed high-dimensional
representation.

\subsection{Random Expansion and Distribution-Based Learning}

RanPAC combines frozen pretrained features with random nonlinear expansion and
analytic decorrelation~\cite{mcdonnell2023ranpac}. FLY-CL replaces the dense
random feature map with a fly-inspired sparse projection and WTA code
~\cite{zou2026flycl}. FeCAM and AdaGauss retain class-distribution statistics
rather than a global expanded-code Gram~\cite{goswami2023fecam,rypesc2024adagauss}.
SRQ-FLY neither generates pseudo-features nor stores class exemplars; it
compresses the global analytic state already used by FLY.

\subsection{Quantized Matrix State}

Li et al.~\cite{li2025fourbit} quantize Cholesky factors of Shampoo
preconditioners, retain the diagonal in higher precision, and use error
feedback. This motivates the factor-space design pattern. SRQ-FLY transfers
that pattern to streaming Ridge, uses deterministic groupwise INT8, and does
not currently maintain error-feedback state.

\section{Method}

\subsection{Exact FLY State}

Let $x_i\in\mathbb{R}^{d}$ be a frozen-backbone feature and let
$P\in\mathbb{R}^{m\times d}$ be a fixed sparse projection. FLY produces

\begin{equation}
z_i=\operatorname{WTA}_{\rho}(Px_i)\in\mathbb{R}^{m}.
\label{eq:wta}
\end{equation}

For current-task code matrix $Z_t$ and one-hot targets $Y_t$, Exact FLY updates

\begin{equation}
G_t=G_{t-1}+Z_t^{\top}Z_t,\qquad
Q_t=\operatorname{expand}(Q_{t-1})+Z_t^{\top}Y_t,
\label{eq:exact-update}
\end{equation}

and solves

\begin{equation}
(G_t+\lambda I)W_t=Q_t.
\label{eq:ridge}
\end{equation}

The dominant persistent tensor is $G_t\in\mathbb{R}^{m\times m}$, whose FP32
payload grows as $4m^2$ bytes.

\subsection{Square-Root Streaming Update}

SRQ-FLY represents the regularized system as

\begin{equation}
H_t=G_t+\lambda I=R_t^{\top}R_t,
\label{eq:square-root}
\end{equation}

where $R_t$ is upper triangular with positive diagonal. After the first
Gram--Cholesky update, later tasks decode the previous quantized factor and
compute the triangular factor of

\begin{equation}
\begin{bmatrix}\widehat R_{t-1}\\Z_t\end{bmatrix}
\label{eq:stacked-qr}
\end{equation}

using blocked QR. Thus, in exact arithmetic for the decoded state,

\begin{equation}
R_t^{\top}R_t=
\widehat R_{t-1}^{\top}\widehat R_{t-1}+Z_t^{\top}Z_t.
\label{eq:qr-identity}
\end{equation}

This is a deterministic approximate recursion after the first quantization; it
is not identical to the historical Exact-FLY Gram.

\subsection{Mixed-Precision Factor Storage}

For a group $r$ in the strict upper triangle, the implementation uses

\begin{equation}
s(r)=\frac{\max_j|r_j|}{127},\qquad
q_j=\operatorname{clip}_{[-127,127]}
\left(\operatorname{round}\left(r_j/s(r)\right)\right).
\label{eq:quantization}
\end{equation}

Each group stores one FP32 scale and INT8 payload values. The diagonal of
$R_t$ remains FP32. The classifier is obtained without a matrix inverse by
solving

\begin{equation}
\widehat R_t^{\top}V_t=Q_t,\qquad
\widehat R_t W_t=V_t.
\label{eq:triangular-solve}
\end{equation}

\begin{theorem}[Structural positive definiteness]
If the decoded upper-triangular factor $\widehat R_t$ is nonsingular, then
$\widehat H_t=\widehat R_t^{\top}\widehat R_t$ is symmetric positive definite.
\end{theorem}

\begin{proof}
For every nonzero vector $v$,
$v^{\top}\widehat H_t v=
\|\widehat R_t v\|_2^2>0$ because nonsingularity implies
$\widehat R_t v\neq 0$. Symmetry follows directly from the product form.
\end{proof}

The theorem is structural: it does not state that $\widehat H_t$ equals the
Exact-FLY system or that prediction is unchanged under arbitrary quantization
error.

\subsection{Cumulative Perturbation and Prediction Stability}

Let $A_t=A_{t-1}+Z_t^\top Z_t$, with $A_0=\lambda I$, denote the Exact
Ridge system. Let $\bar R_t$ be the unquantized triangular output of the QR
update from $[\widehat R_{t-1};Z_t]$, and write the decoded stored factor as
$\widehat R_t=\bar R_t+E_t$. Define
$\widehat A_t=\widehat R_t^\top\widehat R_t$ and
$\Delta_t=\widehat A_t-A_t$.

\begin{proposition}[Cumulative system perturbation]
The effective-system error obeys the exact recurrence
\begin{equation}
\Delta_t=\Delta_{t-1}+D_t,\qquad
D_t=\bar R_t^\top E_t+E_t^\top\bar R_t+E_t^\top E_t,
\label{eq:error-recurrence}
\end{equation}
and hence
\begin{equation}
\|\Delta_t\|_2\le
\sum_{k=1}^{t}\left(
2\|\bar R_k\|_2\|E_k\|_2+\|E_k\|_2^2
\right).
\label{eq:cumulative-bound}
\end{equation}
\end{proposition}

\begin{proof}
Expanding $(\bar R_t+E_t)^\top(\bar R_t+E_t)$ and using
$\bar R_t^\top\bar R_t=\widehat A_{t-1}+Z_t^\top Z_t$ gives
Eq.~\ref{eq:error-recurrence}. Summing the recurrence and applying
submultiplicativity and the triangle inequality gives
Eq.~\ref{eq:cumulative-bound}.
\end{proof}

The bound is worst-case and may be loose because it ignores cancellation; it
does not imply that realized errors must grow monotonically. It does,
however, distinguish the local factor error $E_t$ from the accumulated system
error $\Delta_t$.

Let $Q_t$ be the shared target statistic, $W_t=A_t^{-1}Q_t$, and
$\widehat W_t=(A_t+\Delta_t)^{-1}Q_t$. If
$\epsilon_t=\|A_t^{-1}\Delta_t\|_2<1$, standard inverse perturbation gives
\begin{equation}
\frac{\|\widehat W_t-W_t\|_F}{\|W_t\|_F}
\le \frac{\epsilon_t}{1-\epsilon_t}.
\label{eq:ridge-perturbation}
\end{equation}
For a feature row $\phi(x)^\top$, the corresponding logits satisfy
$\|\widehat\ell-\ell\|_2\le
\|\phi(x)\|_2\|\widehat W_t-W_t\|_2$. If the Exact top-1 margin is
$\gamma(x)$, then
\begin{equation}
2\|\widehat\ell-\ell\|_\infty<\gamma(x)
\label{eq:margin-certificate}
\end{equation}
is sufficient to preserve the Exact top-1 prediction. It is not necessary:
samples outside the certificate may still agree. These are conditional linear
system bounds, not an optimizer-convergence result inherited from Shampoo.

\subsection{Backend Scope}

The same state update applies to any fixed explicit feature map
$\Phi:\mathbb{R}^{d}\rightarrow\mathbb{R}^{m}$ whose Ridge statistics are
additive. Replacing $Z_t$ in Eqs.~\ref{eq:exact-update}--\ref{eq:qr-identity}
by $\Phi(X_t)$ leaves the backend unchanged. This interface excludes methods
that revise historical features, require covariance downdates or negative
sample weights, or update an inverse-RLS state without a separate equivalent
factor formulation. We therefore evaluate portability on RanPAC's
$\Phi(F)=\operatorname{ReLU}(FW_{\mathrm{rand}})$ map rather than claiming
universal compatibility.

\section{Experimental Protocol}

\subsection{Datasets and Metrics}

Experiments use CIFAR-100, CUB-200-2011, and a disclosed legacy processed
ImageNet-R split with a frozen ViT-B/16 and a width-10,000 FLY code. The
ImageNet-R audit found 19 cross-split duplicate hashes, including 18 with
conflicting labels; its result is therefore not described as content-disjoint
held-out evidence.

Let $a_t$ denote average accuracy over all classes observed after task $t$.
We report

\begin{equation}
\operatorname{AIA}=\frac{1}{T}\sum_{t=1}^{T}a_t,
\qquad A_{\mathrm{final}}=a_T.
\label{eq:metrics}
\end{equation}

Persistent state counts deployed learner tensors only. Feature and WTA caches
are experiment infrastructure and are excluded. The update-time ratio is total
SRQ analytic-update time divided by total Exact-FLY analytic-update time; a
ratio above one indicates slower SRQ updates. Same-width accuracy values are
means and sample standard deviations over six class-order and projection
replicates.

\subsection{Baselines and Controls}

The primary baseline is width-10,000 Exact FLY. State-matched Exact FLY reduces
its width to the largest value whose persistent tensor bytes do not exceed
SRQ-FLY's state. Raw Ridge operates directly on 768-dimensional ViT features.
The mechanism ablation additionally compares an unmodified direct-INT8 Gram,
a label-free Weyl-certified direct-INT8 Gram repair, and an FP16 square-root
factor. On the RanPAC frontend, the equal-budget control derives a reduced
Exact width and a signed CountSketch dimension solely from total persistent
tensor bytes before encoding features or observing accuracy. Each distinct
representation selects its Ridge coefficient on the same disjoint train-only
calibration partition.

\subsection{Controlled RanPAC Transfer}

The non-FLY gate uses the Phase-2 random-ReLU analytic head of
RanPAC~\cite{mcdonnell2023ranpac}: a fixed standard-normal projection from 768
to 10,000 dimensions followed by ReLU. A nested training partition selects
one Ridge coefficient by mean-squared error before outer validation. That
coefficient, projection, expanded features, class order, and task grouping are
then shared by the direct Gram reference, generic Exact Gram, dense FP32
square-root, FP16 square-root, and P2B. This controlled experiment does not
reproduce RanPAC's PETL stage or its original per-task Ridge-selection
schedule; it isolates the analytic-backend question.

\subsection{Controlled GACL-Style Generalized Stream}

To test a different update regime, we adapt the inverse-RLS equations of
GACL~\cite{zhuang2024gacl} to the equivalent primal additive-Ridge system. The
locked control uses a width-5,000 bias-free random linear--ReLU map,
$\gamma=100$, and a five-task fixed Si-Blurry stream with $N=50$ and $M=10$.
Old and newly exposed classes can coexist in a mini-batch, and all four
backends update after the same 35 mini-batches: the GACL inverse-RLS reference,
FP32 square-root, FP16 square-root, and P2B. The experiment uses one seed, 2,000
fit and 500 validation samples drawn only from CIFAR-100 training data,
cached ViT-B/16 features, and \texttt{online\_iter}=1. It therefore tests the
equation adapter and compression schedule, not the published end-to-end GACL
system with DeiT-small, augmentation, and \texttt{online\_iter}=3.

\section{Limitations and Discussion}

SRQ-FLY is an accuracy--memory trade-off, not an accuracy improvement over
same-width Exact FLY. Its analytic update is slower because it decodes the
factor, applies blocked QR, re-encodes the strict upper triangle, and performs
triangular solves after each task. Its 97--105 MB state also remains much
larger than raw-feature Ridge. The current implementation is INT8 rather than
true packed INT4 and has no error feedback.

System memory has been measured in four paired repetitions, but only on
CIFAR-100, one Tesla T4, and one software stack. All accuracy experiments use
one frozen ViT-B/16. Repeated final evaluations reuse
the same dataset test split, so replicate variation reflects class order and
projection seeds rather than new dataset sampling. The ImageNet-R split has a
known duplicate-content limitation. Feature and WTA caches contain
sample-level data and must not be included in a deployed checkpoint or counted
as evidence that the complete experiment is sample-free.

Future work should optimize the factor update, repeat process-isolated memory
measurement on other GPU architectures, evaluate packed INT4 with real byte accounting, and test
error-feedback variants whose residual state is included in the memory budget.
Additional untouched datasets and backbones are required before making broad
generalization claims. The RanPAC transfer currently uses one train-only
development seed, omits PETL, and replaces the original per-task Ridge
schedule with one fixed train-only-selected coefficient so that every backend
solves the same additive system. It establishes frontend portability, not a
reproduction of published RanPAC accuracy. The one-seed equal-budget control
rules out reduced-width Exact, one fixed signed CountSketch, and raw Ridge as
dominators on that stream, but does not cover learned sketches, low-rank or
Nystr\"om approximations, other widths, or other datasets. It also exposes a
large update-time disadvantage relative to the equal-budget controls.
The width sweep further exposes a formal accuracy-retention failure at width
20,000: the P2B gap exceeds the locked limit by 0.005845 AIA points. Although
FP16 and solver diagnostics remain stable, the present evidence does not show
that fixed INT8 precision scales without increasing approximation loss. The
task-wise diagnostic is consistent with cumulative effective-system drift and
stronger downstream amplification at 20k, but its one-seed randomized probes
do not establish causality or ill-conditioning.
The adaptive follow-up recovers the locked 20k retention gate using a fixed
25\% allowance toward FP16 storage, but increases state and update time.
Conversely, same-byte scale refinement reduces local reconstruction error yet
still exceeds the 20k gate by 0.000115 points. This negative control warns that
factor reconstruction MSE is not by itself a sufficient proxy for downstream
classification error.
The GACL-style experiment is likewise a controlled equation-level adapter,
not an official reproduction: it uses one seed, a small train-only subset,
cached ViT-B/16 features, no image augmentation, and
\texttt{online\_iter}=1. Although it includes class reappearance and matched
mini-batch-frequency compression, it cannot establish compatibility with
GACL's changing representation, published accuracy, or every generalized
stream. Its growing P2B logit drift and 3.79-times update cost relative to the
inverse-RLS reference are explicit limitations.

\section{Conclusion}

SRQ-FLY compresses the analytic state of FLY without reducing its
10,000-dimensional representation width. Mixed INT8/FP32 square-root storage
reduces persistent state by approximately four fifths while causing only small
same-width AIA changes. State-matched and direct-quantization controls support
the value of preserving representation width and positive-definite factor
structure. Repeated whole-process measurement confirms a smaller, though still
meaningful, runtime-memory benefit. The principal remaining cost is slower
analytic update. A controlled RanPAC transfer demonstrates that the backend
is not tied to FLY's sparse WTA code, while a controlled GACL-style stream
demonstrates the same primal backend under class reappearance and
mini-batch-frequency updates. The present evidence therefore supports a
reusable-backend claim for the explicitly tested fixed-feature additive-Ridge
settings, not an arbitrary learner. An equal-budget experiment supports preserving
the full representation width over the tested reduced-width and signed-sketch
alternatives, while exposing much slower analytic updates. The evidence does
not support superiority on every metric, global Pareto optimality, or
universal plug-in compatibility. A seven-width diagnostic also shows that the
memory advantage grows with width but fixed INT8 narrowly fails the locked
accuracy-retention gate at width 20,000. A task-wise follow-up connects this
failure to growing system, weight, and logit discrepancies, in agreement with
the derived cumulative perturbation recurrence, while leaving causal and
conditioning claims open. A fixed-budget adaptive-precision variant recovers
the 20k development gate at additional state and update cost, whereas a
same-byte scale refinement reduces local factor error but formally misses the
same gate by 0.000115 points.
